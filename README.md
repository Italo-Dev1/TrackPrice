# TrackPrice
Aplicação para monitoramento e análise de preços utilizando Python e Django, integrando coleta automatizada de dados, persistência em banco de dados e dashboard web para visualização dos resultados.

---

## Objetivo do Projeto

Centralizar o acompanhamento de preços de produtos, permitindo:
- Visualizar métricas gerais (preço médio, menor e maior preço)
- Identificar produtos mais caros
- Evoluir para análises históricas e relatórios
